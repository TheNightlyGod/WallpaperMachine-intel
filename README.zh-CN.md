## 快速开始

1. **下载**最新版本的[免费磁盘映像](https://www.wallpapermachine.app/download)。
2. **安装**：打开它，把 WallpaperMachine 拖到“应用程序”文件夹。
3. **打开它。** 下载版暂未经过公证，macOS 会拦下首次启动：在“系统设置 → 隐私与安全性”中点按一次**仍要打开**即可。

接下来由首次使用引导带你完成设置，此后应用会自行更新。[安装指南](https://www.wallpapermachine.app/zh/guides/install/)配有图片，逐步介绍每一个步骤。

- **开箱即用：** 内置视频壁纸 Aurora Drift、pixiv 插画、你自己的视频和图片，以及无需登录即可浏览整个创意工坊。
- **使用拥有 Wallpaper Engine 的 Steam 账户：** 从创意工坊下载，以及播放场景壁纸；场景壁纸需要用到你所拥有的 Wallpaper Engine 中的共享资源。

更想自己构建？只需两条命令，见[开源与自行构建](#开源与自行构建)。

## 为什么值得信任

- **全部开源。** 应用、渲染器和场景引擎都在这个仓库中，以 GPL-2.0 许可证发布。没有闭源核心，也没有付费功能：每个人用到的应用都一样。
- **公开构建。** 每个版本都由 [GitHub Actions](docs/release.md#build-buildyml) 从打了标签的提交构建并测试，然后附带 SHA-256 校验和与构建来源证明（build provenance attestation）发布。验证下载的文件确实来自本仓库的工作流：
  ```sh
  gh attestation verify WallpaperMachine-*-arm64.dmg --repo WallpaperMachine/WallpaperMachine
  ```
- **没有追踪。** 应用只在你需要时联网：Steam 用于创意工坊，pixiv 在你打开它时使用，GitHub 用于检查更新；只有在你打开[发送性能数据](docs/features/telemetry.md)后，才会每天发送一份小报告，内容是加载耗时、帧率和你的 Mac 型号。报告不包含名称、文件或账户信息，关闭后会删除已发送的数据。登录信息和密码保存在你的 Mac 上。
- **可校验的更新。** 内置更新程序只安装 SHA-256 与发布版本一致的磁盘映像；无法验证的会被[拒绝，绝不会未经校验就安装](docs/features/updates.md#downloading)。
- **持续维护。** 新版本发布频繁，每一版都以英文和简体中文写进[更新日志](CHANGELOG.md)。
- **问题有处可报。** 任意壁纸详情中的**无法正常使用？在 GitHub 上反馈**会打开一个预先填好的 [issue](https://github.com/WallpaperMachine/WallpaperMachine/issues)；[诊断报告](docs/features/diagnostics.md)会在你分享之前移除你的个人文件夹路径、Mac 用户名和 Steam 账户名。

## Rust 核心 · Metal 图形

| 层 | 作用 |
| --- | --- |
| **Swift 外壳** | AppKit 应用。控制面板是 `WKWebView` 中的 HTML（[`WebUI/`](WebUI)），[网页壁纸](docs/features/web-wallpapers.md)在各自的 web view 中运行。 |
| **Rust 核心** | 内置的渲染器（[`upstream/renderer`](upstream/renderer)）：负责显示器、壁纸窗口、视频解码和音频捕获，通过 uniffi 桥接到 Swift。 |
| **C++ 场景引擎** | Open Wallpaper Engine，静态链接进 Rust 核心，负责绘制场景壁纸。 |
| **Metal** | 场景直接用原生 Metal 渲染，原生渲染器无法绘制的场景会回退为经由 MoltenVK 在 Metal 上运行的 Vulkan。AVFoundation 视频可在[设置 → 性能](docs/features/performance.md)中选择开启，场景渲染器也可在那里改为兼容模式。 |
| **锁定屏幕** | 一个沙盒化的 ExtensionKit 扩展（[`Extension/`](Extension)）。 |

各部分如何协作：[docs/architecture.md](docs/architecture.md)。每个文件放在哪里：[docs/repository-layout.md](docs/repository-layout.md)。

## 常见问题

换一片风景之前，先了解这些。

<details>
<summary><b>WallpaperMachine 是什么？</b></summary>

WallpaperMachine 是一款面向 Wallpaper Engine 壁纸的原生 macOS 客户端。它把场景、视频和网页壁纸带到你的桌面，并内置 Steam 创意工坊浏览与下载。

</details>

<details>
<summary><b>Mac 上能用 Wallpaper Engine 吗？</b></summary>

Wallpaper Engine 本身是为 Windows 打造的。WallpaperMachine 是一款独立的 Mac 应用，用来播放它的场景、视频和网页壁纸，并内置 Steam 创意工坊浏览；兼容性因壁纸而异。它与 Wallpaper Engine 及 Valve 均无关联。详见[Mac 上的 Wallpaper Engine](https://www.wallpapermachine.app/zh/guides/wallpaper-engine-on-mac/)。

</details>

<details>
<summary><b>需要购买 Wallpaper Engine 吗？</b></summary>

无需登录即可浏览创意工坊。从创意工坊下载需要一个拥有 Wallpaper Engine 的 Steam 账户，场景壁纸还需要已购买的 Wallpaper Engine 安装中的共享资源。内置的视频壁纸 Aurora Drift 两者都不需要。下载如何进行，见[在 Mac 上使用 Steam 创意工坊](https://www.wallpapermachine.app/zh/guides/steam-workshop-on-mac/)。

</details>

<details>
<summary><b>适用于哪些 Mac？</b></summary>

WallpaperMachine 为搭载 Apple 芯片（M1 或更新机型）、运行 macOS 15 Sequoia 或更高版本的 Mac 打造；动态锁屏需要 macOS 26 Tahoe 或更高版本。不支持 Intel 芯片的 Mac。

</details>

<details>
<summary><b>所有壁纸都能用吗？</b></summary>

WallpaperMachine 支持场景、视频和网页渲染。兼容性因壁纸而异；支持这些格式并不代表每个创意工坊项目都能呈现完全一致的效果，应用程序（Application）类壁纸也无法运行。如果某张壁纸显示不对，在它的详情中点按**无法正常使用？在 GitHub 上反馈**，会打开一个填好该壁纸信息的新 [GitHub issue](https://github.com/WallpaperMachine/WallpaperMachine/issues)，供你检查后提交。如需附上日志，请在“设置 → 存储 → 故障排查”中导出[诊断报告](docs/features/diagnostics.md)，其中的个人文件夹路径、Mac 用户名和 Steam 账户名会先被替换掉。

## 开源与自行构建

完整源代码就在这里。构建需要搭载 Apple 芯片的 Mac、Xcode 26（macOS 15.6 或更高版本）、用 `xcode-select` 选定的完整 Xcode，以及[先决条件](docs/build.md#prerequisites)中列出的 Homebrew 软件包；渲染器和场景引擎内置在[`upstream/`](upstream) 中，而不是以子模块引入。

```sh
python3 scripts/install_ffmpeg.py                  # 本项目的 LGPL FFmpeg 构建
python3 scripts/build.py --configuration Release   # 渲染器、绑定、Xcode 项目和应用
```

构建好的应用位于 `build/Build/Products/Release/WallpaperMachine.app`。`python3 scripts/test.py` 运行测试，`python3 scripts/package.py --configuration Release --install` 会让应用包自包含、封装成磁盘映像，并复制到 `~/Applications`。场景壁纸同样需要你所拥有的 Wallpaper Engine 中的共享资源。

工具链、打包和故障排查：[docs/build.md](docs/build.md)。参与开发：[CONTRIBUTING.md](CONTRIBUTING.md)。
